# Contributing

Thank you for helping `ax-lint` track a fast-moving AX contract.

Use Node.js 20 or newer. Fork the repository, create a focused branch, add behavior-first tests, and run `npm run format:check`, `npm run lint`, `npm run typecheck`, `npm run test:coverage`, `npm run build`, and `npm run check:package`.

Contract changes need a link to exact upstream Google AX evidence and fixtures proving the behavior. Security and best-practice checks must remain policy rules with a documented rationale. Do not infer fields or relationships.

Use Conventional Commits and keep pull requests focused.
