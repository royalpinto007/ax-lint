# Security policy

Report vulnerabilities privately through [GitHub Security Advisories](https://github.com/royalpinto007/ax-lint/security/advisories/new). Do not open a public issue for an unpatched vulnerability.

Supported versions are listed in GitHub releases. The latest release receives security fixes.

`ax-lint` parses untrusted local YAML. Reports should include the smallest safe reproducer, affected version, expected impact, and proposed mitigation when available. Never include live credentials.
